# ReaperScripts

My REAPER scripts, distributed through ReaPack.

Import this repository in **Extensions → ReaPack → Import repositories**:

```text
https://raw.githubusercontent.com/ErrrikMarrrtinez/ReaperScripts/master/index.xml
```

- [Markdown editor and Multiline input library](Various/Markdown/README.md): a native ReaImGui editor and embeddable Lua text field, with plain-text and live Markdown modes.
- [Track View Manager](Various/Track%20View%20Manager): track view tools.

# Проверка 0.7.0

Если сейчас открыто окно **0.6**, перед его закрытием сними его обработку кнопкой Remove отдельно в De-ess и Breaths на нужных айтемах. Либо верни исходную огибающую через Undo/копию проекта. Кэш исходника из памяти старого окна перенести невозможно. В 0.7 повторное открытие скрипта уже сохраняет это состояние до закрытия самого REAPER.

Запусти `mrtnz_Vocaligner.lua`; Copy report должен начинаться с **Vocaligner 0.7.0**.

1. Открой Breaths с включённым **Auto** и выбери один айтем: чтение/восстановление кэша и применение запускаются сами. Для ручного режима отключи Auto; **Get** делает захват + анализ + применение одной кнопкой.
2. Для сравнения начни с **Sensitivity 50, Minimum duration 80 ms, Join gaps 160 ms, Find edges 120 ms**. Старые значения ручек сохранены, поэтому 100/40 могут дать лишние срабатывания. Reduction, Fade in/out и Target настрой по слуху.
3. На том же айтеме настрой De-ess, переключись на Breaths, вернись обратно. Каждый инструмент должен сохранить свой слой. Remove снимает только активный; удаление обоих возвращает исходную огибающую.
4. Закрой только скрипт и открой снова. Выбери обработанный айтем: настройки и анализ должны восстановиться без накопления ослабления. Затем проверь перемещение, обычную подрезку и разделение айтема, в том числе при закрытом скрипте. В отчёте есть строка `cache status`.
5. Выделение времени делается только на верхней линейке. Клик по телу волны ставит курсор, перетаскивание двигает обзор. Глобальный тайм-селекшн вне айтема больше не блокирует обработку.

# Живой Markdown

Запуск: `mrtnz_Markdown.lua` через Actions → ReaScript: Load → Run. После обновления файлов остановите и заново запустите скрипт. Нужен ReaImGui с API `0.9.2.3`; Python, браузер, ReaMD и внешний процесс рендера не нужны.

Это одно редактируемое поле. Активная строка или ячейка раскрывает исходную разметку; вне неё отображается оформление. При выделении мышью проекция удерживается, чтобы текст не перемещался под указателем. Копирование возвращает Markdown, включая его исходные маркеры. Кнопка «Исходник» меняет представление того же документа, сохраняя историю и выделение.

«Чтение» скрывает исходные маркеры, блокирует изменение текста и открывает ссылки обычным кликом. Выделение протягиванием и копирование остаются доступны. В режиме редактирования переход по ссылке — Ctrl+клик. Внутренние `#заголовок` и `#^сноска` прокручивают документ к цели; заголовки могут содержать оформление, кириллицу и пробелы или дефисы в адресе.

## Реализовано

- Заголовки 1–6 и Setext, абзацы, мягкий перенос, разделители, цитаты и callout-блоки `> [!tip]`, `> [!warning]` и другие типы. У callout есть сворачивание; `+`/`-` после типа задаёт начальное состояние.
- Жирный, курсив, их вложение, зачёркивание, `==выделение==`, inline-код, экранирование, базовые HTML entities. Поддерживаются inline-теги `b`, `strong`, `i`, `em`, `s`, `del`, `mark`, `code`, `kbd`, `u`, `sup`, `sub`, `br`; это не браузерный HTML renderer.
- При наборе `--` заменяется на длинное тире `—`. Ctrl+Z возвращает два дефиса; код, формулы, ссылки, структурные разделители и вставка из буфера сохраняются буквально. Третий дефис в начале строки позволяет набрать разделитель `---`. Отключение автозамены: `markdown_smart_dashes=false`.
- Маркированные и нумерованные списки, отступы, продолжение пункта по Enter и выход из пустого пункта. Задачи используют настоящие ImGui Checkbox. Выполненный текст приглушается и зачёркивается; переключение входит в undo.
- Ссылки обычные, ссылочные, wiki-ссылки с псевдонимом, теги, сноски с числовыми надстрочными ссылками. Для внешних/wiki-ссылок есть callback; без него HTTP открывается через SWS `CF_ShellExecute`, если он установлен, либо адрес остаётся в `last_link` и строке статуса демки.
- Fenced/indented code, подсветка ключевых слов, строк, чисел и однострочных комментариев. Код показывается буквально, без интерпретации Markdown и без автопереноса. У длинного блока собственная горизонтальная прокрутка: Shift+колесо, горизонтальное колесо или тонкая полоса снизу. Каретка автоматически доводится до видимости; абзацы вокруг блока остаются на месте. Фон блока цельный, язык и компактная кнопка `copy` расположены справа у первой строки. YAML frontmatter сохраняется и показывается как код. Комментарии `%% ... %%` скрываются вне редактирования; inline `<!-- ... -->` также скрывается.
- Локальные изображения в отдельных строках `![alt](path)` и `![[path]]`. Загрузка native-ресурсов происходит в `prepare`, до ImGui Begin. HTTP-изображения показываются карточками; приложение может предоставить локальный путь через `resolve_image`.
- Простые формулы с греческими буквами, операторами и верхними индексами. Небольшие ациклические Mermaid `graph`/`flowchart` TD/TB/LR с рёбрами `-->`, до 40 узлов; клик раскрывает код схемы для редактирования.
- Размеры узлов Mermaid учитывают надписи и масштаб шрифта. При узком окне схема перестраивается по вертикали, высота подстраивается под содержимое. Подсказка редактирования появляется при наведении и не занимает строку.
- Темы Graphite, Paper, Sand, масштаб Ctrl+колесо, undo/redo, открытие/сохранение `.md` и предупреждение о несохранённых изменениях в демонстрации.

## Таблицы

Ячейки редактируются прямо в общей поверхности. Markdown, ссылки и флажки `[ ]` / `[x]` работают внутри ячеек. Добавить флажок можно через Ctrl+Shift+9. Текст после включённого флажка зачёркивается.

На границах строк и над границами колонок появляется `+`. Разделитель в заголовке перетаскивается мышью; изменение ширины пересчитывается до отрисовки кадра. ПКМ открывает добавление, удаление, перестановку строк/колонок, выравнивание, сортировку и переключение таблицы в исходник и обратно. Заголовок и последняя колонка защищены от удаления; таблицу целиком можно удалить обычным выделением исходного диапазона.

| Действие | Клавиши |
|---|---|
| Следующая / предыдущая ячейка | Tab / Shift+Tab |
| Следующая строка, та же колонка | Enter |
| Перенос внутри ячейки (`<br>`) | Shift+Enter |
| Добавить строку после последней | Tab в последней ячейке или Enter в последней строке |
| Удалить текущую строку | Ctrl+Shift+Backspace; также Backspace в начале первой ячейки пустой строки |
| Удалить текущую колонку | Ctrl+Shift+Delete |
| Выйти из таблицы в абзац ниже | Ctrl+Enter |
| Вставить сетку с табуляциями из буфера | Ctrl+V; при необходимости добавляются строки/колонки |

Табличные действия и вставка сетки — одна транзакция undo. Вставляемые буквальные `|` экранируются. Ширины колонок и состояние сворачивания принадлежат экземпляру виджета и не записываются в Markdown; выравнивание записывается в строке разделителей. Поддерживается до 128 колонок.

## Форматирование и файлы

| Действие | Клавиши |
|---|---|
| Жирный / курсив / ссылка / inline-код | Ctrl+B / Ctrl+I / Ctrl+K / Ctrl+E |
| Зачёркивание / цветовое выделение | Ctrl+Shift+X / Ctrl+Shift+H |
| Блок кода / цитата | Ctrl+Shift+C / Ctrl+Shift+Q |
| Нумерованный список / маркированный / задача | Ctrl+Shift+7 / Ctrl+Shift+8 / Ctrl+Shift+9 |
| Заголовок 1–6 | Ctrl+Alt+1…6 |
| Переключить задачу вне таблицы | Ctrl+Enter |
| Отмена / повтор | Ctrl+Z / Ctrl+Shift+Z или Ctrl+Y |
| Масштаб | Ctrl+колесо |
| Открыть / сохранить / сохранить как — в демке | Ctrl+O / Ctrl+S / Ctrl+Shift+S |

Остальные стандартные операции выделения, перемещения, буфера и удаления сохраняются. Изображение, callout, формулу и разделитель можно вставить разметкой или через API `format`. Демонстрация оставляет компактную панель режимов и темы; файловые операции и форматирование доступны с клавиатуры. Поиск и замена доступны через API базового редактора; отдельной панели Ctrl+F/H пока нет.

## Подключение и настройки

```lua
local field = Multiline.new({
  text = '# Заметка\n\n- [ ] Задача',
  markdown = true,
  markdown_shortcuts = true, -- форматирование работает и в режиме исходника
  font_family = 'Arial',
  code_font_family = 'Consolas',
  font_size = 18,
  padding = 24,
  line_spacing = 1.2,
  list_item_spacing = 3, -- дополнительный интервал задач/маркеров; без опции масштабируется со шрифтом
  inline_code_offset = 0.1, -- поправка положения inline-кода, в долях размера его шрифта
  table_padding_x = 8,
  table_padding_y = 5,
  markdown_max_width = 900,
  markdown_theme = 'graphite',
  markdown_base_path = '/path/to/notes/', -- директория с завершающим разделителем
  on_open_link = function(editor, url)
    -- Приложение решает, как открывать URL и wiki-ссылки.
  end,
  resolve_image = function(editor, path)
    -- Вернуть локальный путь либо nil для карточки без изображения.
    return path
  end,
})
```

Как и для обычного поля, каждый кадр вызывайте `field:prepare(ctx, im)` **до** `im.Begin`, затем `field:render(...)`, при завершении — `field:dispose()`. `field:set_markdown(false/true)` переключает режим; с подключённым UI переключение применяется в следующем `prepare`, когда можно безопасно подготовить шрифты.

`field:set_read_only(true/false)` переключает режим чтения без замены документа и истории. Включите также `markdown=true`, если нужно оформленное представление. `markdown_smart_dashes=false` отключает замену двух дефисов при наборе.

`field:format(command, value)` принимает `bold`, `italic`, `strike`, `highlight`, `code`, `code_block` (value — язык), `math`, `link`, `image` (value — адрес), `heading` (уровень 1–6), `bullet`, `ordered`, `task`, `quote`, `callout`, `rule`, `table` (число колонок), `toggle_task`.

`markdown_theme` может быть именем темы или полной таблицей цветов из `markdown/theme.lua`. Межстрочный интервал задаётся множителем высоты шрифта; минимальная высота оставляет место для текста и native-флажка. Задачи и маркированные пункты имеют дополнительный интервал между пунктами; нумерованные списки и переносы внутри пункта его не получают. Пустая строка после заголовка отображается компактнее. В живом Markdown абзацы и ячейки переносятся, а блоки кода прокручиваются горизонтально; `set_wrap` управляет обычным текстовым режимом.

Размеры H1–H6 составляют `1.80 / 1.64 / 1.48 / 1.32 / 1.16 / 1.00` от базового шрифта. H5 и H6 различаются; отступы масштабируются вместе с текстом. Одна пустая исходная строка между заголовками входит в общий отступ, сохраняя собственную область для каретки и выделения. Дополнительные пустые строки остаются видимыми.

## Геометрия и ограничения

`document.text` остаётся единственным исходником. Inline-проекция сопоставляет видимый текст исходным байтовым диапазонам. Табличные ячейки используют базовую раскладку с переносами, но отдельного редактируемого документа или InputText внутри них нет. История хранит изменения исходника, а не результат рендера.

Количество визуальных рядов и высоты блоков индексируются отдельно. При изменении ширины не пересоздаются индексы всех исходных строк: сначала рассчитывается видимая область, остальное уточняется в пределах бюджета. Прежние мини-layout и проекции переиспользуются. При изменении текста блоковый парсер пока делает линейный проход документа; это не полностью инкрементальный Markdown-парсер. Проверка 20 000 строк подтверждает сохранение индексов при resize, но не является измерением FPS внутри REAPER.

Это самостоятельная реализация живого Markdown, а не полная копия движка Obsidian/CommonMark. Сложный LaTeX не проходит через MathJax/KaTeX. Mermaid поддерживает только описанное подмножество; неподдержанный синтаксис остаётся кодом. Произвольный HTML, vault/backlinks, плагины Obsidian, полная Unicode-сегментация графем и bidi не реализованы. `sup`/`sub` пока получают приглушённый стиль; отдельная надстрочная геометрия есть у сносок. Исходная разметка этих конструкций не удаляется.

Проверки Lua 5.4, адаптера ReaImGui, истории, таблиц, переключения режимов, ресурсов, масштаба и resize выполнены отдельно от проекта. Они моделируют UI-вызовы; окончательную оценку native-шрифтов и поведения указателя даёт запуск в REAPER. В папке модуля нет проверочных скриптов или Python-зависимостей.
